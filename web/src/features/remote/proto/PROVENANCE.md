## Generated code

`gen/` is generated by `pnpm gen:proto` and committed: `buf generate` (the `@bufbuild/buf`
dev dependency, which brings its own compiler) runs the local `@bufbuild/protoc-gen-es`
with the options in `buf.gen.yaml` (`target=js+dts,import_extension=js`). No system
`protoc` is needed. `pnpm lint` regenerates it and fails on any difference
(`gen:proto:check`). buf 1.75.0, libprotoc 3.21.12 and libprotoc 36.2 all produce
byte-identical output.

`js+dts` rather than `ts`: protoc-gen-es writes TypeScript `enum`s for `target=ts`, which
the console's `erasableSyntaxOnly` compiler setting rejects.

To move to a newer client tag: copy the file from that tag, update this table (tag,
commit, sha256), run `pnpm gen:proto`, and re-run the handshake fixtures.
